Ciao classe
esercizio di oggi: React fetch API
nome repo: react-api

Utilizzando la seguente API:
https://dummyjson.com/docs/recipes

Creare un componente in react che, prendendo i dati dall'API, mostri nella UI un elenco di ricette. I dati devono essere visualizzati subito alla visualizzazione (mounting) del componente.

Mostrare un loader mentre prendiamo i dati. Potete usare questo snippet per simulare un delay della risposta, come abbiamo visto a lezione:
// Fake delay
await new Promise(resolve => setTimeout(resolve, 2000));

Utilizzare try/catch per gestire il caso in cui abbiamo un errore nella risposta dell'api (response.ok ci restituisce false)
